# Data-Analysis
# 📊 Data Analytics Internship Projects

A complete Data Analytics portfolio containing six practical projects covering
Sales Analytics, Customer Retention, Web Analytics, HR Analytics,
Financial Analysis, and an End-to-End Capstone Project.

---

## 👨‍💻 About This Repository

This repository contains the projects completed as part of a Data Analytics
internship project program.

The objective of this portfolio is to demonstrate how raw business data can
be transformed into meaningful insights through:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Excel Analysis
- Data Visualization
- KPI Analysis
- Customer Segmentation
- Funnel Analysis
- Statistical Analysis
- Time-Series Analysis
- Dashboard Development
- Business Recommendations
